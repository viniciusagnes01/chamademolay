# Chama DeMolay

Site estático para a candidatura Chama DeMolay ao Gabinete Nacional 2026/2027.

## Estrutura

- `index.html`: conteúdo e seções da campanha.
- `styles.css`: identidade visual, responsividade e animações.
- `script.js`: menu mobile, navegação ativa, revelação de seções e partículas.
- `assets/`: brasões, louros e elementos visuais da Chama DeMolay.

Abra `index.html` no navegador para visualizar.
